# Demo script (about 7 minutes; record only after exercising the live app)

This is a recording plan, not evidence of a completed demo. Use a course and providers that are actually configured. If a step cannot be shown live, say so and do not substitute fabricated output.

| Time | Walkthrough |
|---|---|
| 0:00–0:30 | Explain fragmented study sources and the source-grounding goal. |
| 0:30–1:30 | Upload a real PDF, slide deck, and (if FFmpeg/STT are configured) a short video; show actual ingestion status and any warnings. |
| 1:30–2:15 | Open the knowledge view; show real topics and any indexed figure thumbnails, including AI-written labels where applicable. |
| 2:15–3:30 | Ask an answerable course question; follow its citation to the PDF page, slide, or timestamp. Then ask an unsupported question and show the actual response. |
| 3:30–5:00 | Create and complete a scoped assessment; show topic, difficulty, source references, verified questions, grading, cited feedback, and inferred misconception labels. |
| 5:00–6:00 | Show the learner estimate, evidence count, recommendations, and no-repeat behavior. Explain that BKT parameters are fixed and estimates are not measured learning gains. |
| 6:00–7:00 | Open Evaluation. If no real runs exist, show the honest empty state. Explain that optional RAGAS integration exists but has no verified live run or approved team dataset; do not present drafts or synthetic outputs as benchmark results. |

Record English audio or subtitles. Keep the final video between 3 and 10 minutes and publish it as public or unlisted on YouTube, not private. Capture real screens only; redact account identifiers and secrets.
