## Focused findings requested by Prompt 0

1. Tutor conversations can add one bounded struggle event per grounded conversation/topic when the student explicitly requests simpler help, asks for prerequisites, or repeats questions. Neutral turns do not imply mastery.
2. Figure support is partial: Substantial embedded PDF/PPTX images can be OCR'd and optionally described by a vision LLM; decorative assets are filtered and authorized thumbnails resolve from exact page/slide refs. Live vision retrieval and video keyframes remain unverified/not implemented.
3. Prerequisites are not generated in heuristic/offline topic mode. They can be supplied by an LLM topic build or added manually.
4. Generated assessment questions carry a topic, difficulty, and source association. `backend/app/tests/test_assessment.py::test_offline_questions_are_verified_sourced_and_tagged` checks topic/difficulty and source-backed explanations; numerical question tests cover deterministic answer computation. Student-facing question payloads intentionally withhold answer keys and citations until results.
